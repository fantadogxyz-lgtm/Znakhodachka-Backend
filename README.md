# Znakhodachka - Backend 

**Znakhodachka** (Находочка) - это социальная платформа для поиска и обмена необычными, малоизвестными и красивыми местами Беларуси.

> ⚠️ **Статус проекта:** В активной разработке. 
> Проект создается для республиканского конкурса **«100 идей для Беларуси»**. 
> Реализован основной костяк: аутентификация, публикации, сообщества и обсуждения. Впереди - рефакторинг, оптимизация работы с бд и тд и тп.

Данный репозиторий содержит **backend-часть** приложения: REST API, работу с базой данных, систему аутентификации, загрузку медиафайлов и логику социального взаимодействия.

### Основной функционал
*   **Аутентификация и авторизация:** Регистрация и вход пользователей с использованием JWT.
*   **Публикации (Посты):** Создание постов с фотографиями, геолокацией, описанием и категориями.
*   **Сообщества:** Тематические группы (до 3-х на аккаунт), вступление, теги и публикация контента в рамках сообществ по тематике.
*   **Обсуждения (Discussions):** Легковесный аналог тредов (как в Twitter/Threads). Поддержка комментариев с плоской структурой вложенности. Обсуждения встроены в сообщества
*   **Работа с геоданными:** Использование PostGIS для привязки постов и обсуждений к координатам на карте.
*   **Работа с медиа:** Интеграция с MinIO для загрузки и хранения фотографий.

### Стек технологий и инструментов
*   **Язык:** Java 25
*   **Фреймворк:** Spring Boot, Spring Web, Spring Security (JWT), Spring Data JPA
*   **База данных:** PostgreSQL (с расширением **PostGIS** для геоданных)
*   **Миграции:** Flyway
*   **Маппинг:** MapStruct, Lombok
*   **Хранилище файлов:** MinIO
*   **Сборка и развертывание:** Maven, Jib (сборка Docker-образов), Docker Compose

### Как запустить локально
В проекте лежат файлики docker-compose.yml + .env
